Detail temuan audit

Backup dan pemulihan data

Ekspor JSON membuat salinan data lokal. Impor JSON akan mengganti seluruh data yang tersimpan setelah struktur dan ID diperiksa. Simpan backup sebelum melakukan impor.

Format yang didukung: array record JSON atau objek JSON dengan properti records. File yang tidak valid tidak akan mengganti data saat ini.

Ruang lingkup dan batasan

  • Prototype portofolio untuk demonstrasi audit kelengkapan dan kualitas data rekam medis.
  • Mesin audit menggunakan aturan sederhana (rule-based), bukan model AI/LLM.
  • Validasi kode ICD-10 hanya memeriksa pola penulisan dasar, bukan memastikan kode resmi atau ketepatan klinis.
  • Data disimpan di LocalStorage browser perangkat ini; hapus data situs/browser dapat menghilangkannya.
  • Aturan kelengkapan merupakan indikator review, bukan keputusan klinis atau keputusan klaim otomatis.
  • Jangan masukkan data pasien nyata, NIK, alamat, nomor telepon, atau informasi yang dapat mengidentifikasi seseorang.

Dikembangkan sebagai proyek demonstrasi pembelajaran informatika kesehatan. Keputusan klinis dan kodifikasi akhir tetap memerlukan validasi profesional.
