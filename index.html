Mode demonstrasi: gunakan data sintetis/fiktif saja. Data disimpan di browser melalui LocalStorage. Bukan sistem produksi, bukan database klinis, dan bukan pengganti verifikasi koder/DPJP.

Pencarian Alphabetical Index ICD-10

Sumber indeks yang dipakai adalah ICD-10 Volume 3 (Alphabetical Index), edisi 2016. Tabular yang dibandingkan adalah WHO ICD-10 2019. Karena edisinya berbeda, hasil hanya pembanding teknis, bukan validasi kode final atau standar klaim Indonesia. Bagian III (tabel obat dan bahan kimia) belum diindeks. Matriks kecelakaan transportasi darat WHO dilewati agar kode dari kolom tabel berbeda tidak tercampur.
Referensi diproses satu kali per browser/perangkat, lalu disimpan lokal di IndexedDB. Saat aplikasi dibuka kembali, referensi dimuat otomatis tanpa memilih ulang file. PDF/TXT asli tidak disimpan; yang disimpan hanya hasil ekstraksi terstruktur. Data tidak dikirim ke server dan tidak tersinkron antarperangkat.

Penyiapan awal: pilih PDF Alphabetical Index 2016 dan file icd102019syst_codes.txt satu kali. Setelah itu pencarian otomatis tersedia pada kunjungan berikutnya di browser yang sama.

Backup dan pemulihan data

Ekspor JSON membuat salinan data lokal. Impor JSON akan mengganti seluruh data yang tersimpan setelah struktur dan ID diperiksa. Simpan backup sebelum melakukan impor.

Format yang didukung: array record JSON atau objek JSON dengan properti records. File yang tidak valid tidak akan mengganti data saat ini.

Ruang lingkup dan batasan

  • Prototype portofolio untuk demonstrasi audit kelengkapan dan kualitas data rekam medis.
  • Mesin audit menggunakan aturan sederhana (rule-based), bukan model AI/LLM.
  • Validasi kode ICD-10 memeriksa pola penulisan dasar. DQ-10 hanya membandingkan daftar contoh diagnosis-kode terbatas, bukan memastikan kode resmi atau ketepatan klinis.
  • Data disimpan di LocalStorage browser perangkat ini; hapus data situs/browser dapat menghilangkannya.
  • Aturan kelengkapan merupakan indikator review, bukan keputusan klinis atau keputusan klaim otomatis.
  • Jangan masukkan data pasien nyata, NIK, alamat, nomor telepon, atau informasi yang dapat mengidentifikasi seseorang.

Dikembangkan sebagai proyek demonstrasi pembelajaran informatika kesehatan. Keputusan klinis dan kodifikasi akhir tetap memerlukan validasi profesional.
